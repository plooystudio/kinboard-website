# kinboard.ca

The public website for Kinboard: home page, Privacy Policy and Terms. Plain static files, published with GitHub Pages at https://kinboard.ca.
The app itself lives at https://app.kinboard.ca (a separate repository, `kinboard-app`).

- `index.html` is the home page. Sign-up buttons go to `app.kinboard.ca/signup?plan=annual` and `?plan=monthly`; Sign in goes to `app.kinboard.ca/login`.
- `privacy/` and `terms/` are the legal pages.
- `assets/` holds the logo and the home-screen picture.
- Change a file, commit, push to `main`: the site updates in about a minute.
- The CNAME file tells GitHub Pages the site's address. Don't delete it.
